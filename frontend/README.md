# 🌍 HopeSphere Frontend

The modern React frontend for **HopeSphere**, built with React 19, Vite 7, and Tailwind CSS v4.

## Quick Start

```bash
npm install
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
npm run build
npm run preview
```
